# لوحة معلومات جمعية أعمال

## نبذة عن المشروع
مشروع لوحة معلومات تفاعلية يهدف إلى عرض ومقارنة مجموعة من مؤشرات جمعية أعمال للتنمية المجتمعية خلال عامي 2024 و2025، من خلال رسوم بيانية ومؤشرات مرئية تساعد على فهم التغيرات بين العامين.

## رابط لوحة المعلومات
[اضغط هنا لعرض لوحة المعلومات التفاعلية](https://afaq-business-dashboard.onrender.com/)

## أهداف المشروع
- مقارنة مؤشرات الجمعية بين عامي 2024 و2025.
- عرض التغيرات في أعداد المستفيدين والفرص والساعات التطوعية.
- تحليل مؤشرات التمويل والمبادرات والبرامج.
- مقارنة الإيرادات والمصروفات بين العامين.
- تسهيل استكشاف البيانات من خلال لوحة معلومات تفاعلية.

## الأدوات والتقنيات المستخدمة
- **Python:** لمعالجة البيانات وتنفيذ العمليات البرمجية.
- **Dash:** لبناء لوحة المعلومات التفاعلية.
- **Plotly:** لإنشاء الرسوم البيانية.
- **GitHub:** لحفظ الكود وإدارة ملفات المشروع.
- **Render:** لنشر لوحة المعلومات وإتاحتها عبر الإنترنت.

## مصادر البيانات
يعتمد المشروع على مجموعة من المؤشرات المنشورة في التقارير السنوية والقوائم المالية لجمعية أعمال لعامي 2024 و2025.

تُستخدم هذه البيانات للمقارنة الاستكشافية بين العامين، وتوضيح التغيرات في المؤشرات. ولا تعني التغيرات الرقمية وحدها إثبات أسبابها أو الحكم النهائي على أداء البرامج.

## هيكل ملفات المشروع

```text
afaq-business-dashboard/
├── README.md
├── afaq_business_dashboard.py
└── requirements.txt
```

- `README.md`: يحتوي على وصف المشروع وأهدافه وتعليمات تشغيله.
- `afaq_business_dashboard.py`: الملف الرئيسي الذي يحتوي على كود لوحة المعلومات.
- `requirements.txt`: يحتوي على المكتبات البرمجية اللازمة لتشغيل المشروع.

## طريقة تشغيل المشروع

### 1. تحميل المستودع

```bash
git clone https://github.com/Jialotaibi/afaq-business-dashboard.git
cd afaq-business-dashboard
```

### 2. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

### 3. تشغيل لوحة المعلومات

```bash
python afaq_business_dashboard.py
```
